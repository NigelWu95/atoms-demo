## 3. 实现结构与依赖

新生产代码集中在 `backend/src/main/java/dev/atoms/demo/source/`，测试集中在对应 `src/test/java/.../source/`。内部 record 可按职责归入类型文件，不为了文件数限制制造万能类。

```text
PS01–PS03  启用边界 → 源码策略 → 受控 Git 进程
    ↓
PS04–PS06  Git 快照读写 → 增量表 → 持久操作意图
    ↓
PS07–PS09  初始化闭环 → 中断恢复 → 有界调度及启动恢复
    ↓
PS10–PS12  旧工程显式导入 → 授权读取 → 工作副本
    ↓
PS13–PS15  封存候选 → 增量接受 → 取消竞态
    ↓
PS16–PS18  新版本恢复 → 有界差异 → 容量/错误/秘密防护
    ↓
PS19–PS20  全链路与旧功能回归 → 使用文档及交接
```

每三项设一个检查点，最后两项设交付检查点。早期虽有基础适配器任务，每项均提供可执行验证；PS07 起持续串通完整服务路径，不到最后才连接数据库和 Git。

高风险前置：Git 不能加载外部钩子/过滤器；先验证独立保存读回，再验证数据库发布；在接入工作副本前完成中断恢复。只设计一个受控磁盘 Worker，不引入消息队列、远程 Git 服务或容器调度器。

## 4. 写入协议与实现细化

1. **准入**：校验功能开关、当前所有者、归档状态和源码基线；对同幂等键比较请求摘要。数据库先记录操作意图及服务器生成的候选版本 ID。
2. **冻结输入**：受控模板或已封存候选形成不可变输入。工作副本句柄绑定项目、基线与任务 ID，不能接受网页或 Agent 自报的任意路径。
3. **Git 阶段**：事务外写对象、树、提交及平台版本引用；重新读取并校验工程摘要。引用更新使用只允许创建或核对同一结果的条件，不覆盖已有引用。
4. **发布阶段**：短事务重新锁定项目与源码记录，检查权限、归档、取消状态和基线，再原子插入版本、移动新模式指针及完成操作。源码已保存不代表已构建。
5. **中断核对**：数据库提交是可见性依据。Git 候选存在但数据库未发布时，不自动将其变为当前版本；能够证明尚未发布的操作安全结束，否则进入 `NEEDS_RECONCILIATION` 并阻止该项目继续写入。数据库已完成则返回原结果，不重复生成版本。

调度器恢复时先核对所有遗留操作，再接受新写入；不自动重放不明确的磁盘任务。已明确失败的操作可由新的幂等键重试，不能把同键变成第二次写入。重试和恢复均重新验证调用者当前权限，不能让旧账号依赖幂等结果继续读取项目。

源码根使用平台标记和稳定的本机租约；相同根的第二个写入者拒绝启用。新工作副本不包含 `.git` 或指向正式仓库的文件。目录、进程和环境过滤不构成安全沙箱，只适用于已确认的受控本机模式。

### 拟定运行预算

源码树沿用已批准的 512 文件、2 MiB/文件、16 MiB/树、240 字节路径、16 层深度。以下为本计划新增的运行控制提案，审批后才成为默认值；与模型 tokens/请求超时无关：

- 一个磁盘 Worker；待处理操作最多 64 个，满额返回明确错误，不无限排队。
- 单次 Git 子进程最多 60 秒，单次源码操作最多 300 秒；超时需确认自有进程结束，未确认前不释放写入准入。
- 错误诊断最多 64 KiB，不输出文件内容、命令中的凭据或完整环境；Git 数据通道按相应文件/树预算读取，不能套用日志截断后继续当作完整内容。
- 差异正文最多 128 KiB，并返回 `truncated` 与完整文件变更统计；读原文件不依赖截断差异。
- 新源码根预算 8 GiB、写入前至少保留 512 MiB 可用空间。超限停止接收新操作，不删除历史；并发之外的外部写盘仍可能耗尽磁盘，所以必须测试 I/O 失败，不能宣称这是硬配额。

配置使用 `atoms.source.*` / `PROJECT_SOURCE_*` 命名，默认关闭，未启用时不探测 Git 或创建目录。源码根、工作副本根和 Git 路径均由维护者显式提供；不修改 `.env.local`。

## 6. 风险与停止条件

| 风险 | 处理方式 |
|---|---|
| Git 与数据库部分成功 | 意图先持久化；不可变候选；短事务发布；未知状态封锁，不自动覆盖 |
| 工作副本被替换或链接越界 | 文件类型/归属/链接检查；先封存后校验；正式仓库不暴露给 Agent；同系统用户仍非隔离 |
| 账号归属在任务中途变化 | 准入、读取、发布和幂等结果返回都重新授权；发布时复查 |
| 同根多写入者或锁失效 | 稳定根租约；单 Worker；锁身份复核；失效即停止写入 |
| 历史和暂存对象耗尽磁盘 | 有界准入、可用空间检查和明确错误；首版不自动 GC/删除 |
| 旧模板清单与新源码树身份混淆 | 导入记录来源，移除旧格式对新树的权威性；不改变旧格式的校验或下载逻辑 |
| 测试意外触发日常配置 | 专用测试 profile、实际 DB 身份校验、Git 子进程环境白名单、模型/邮件适配器禁用 |

涉及新增依赖、改预算、引入公开文件写入接口、执行生成代码、修改个人 Claude Code 配置、真实付费模型调用、远程变更或删除正式数据时，暂停并请求范围确认。源码存储无法可靠解释异常状态时也应暂停该项目写入，不能降低校验让测试通过。
