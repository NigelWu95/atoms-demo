## 运维与未覆盖范围

公网 HTTP 密码功能默认关闭，现有邮箱 HTTP 演示开关不会自动放开它；只在 `.env.local.example` 添加 `PASSWORD_AUTH_ALLOW_INSECURE_HTTP=false` 文档项，没有更改私有值。安全技能影响了专用验证码、会话版本、输入边界与默认传输限制，前端技能影响了共用创建逻辑、状态隔离和响应式可访问页面。

迁移本轮仅在隔离测试库执行；已有账号不会自动生成密码。以后部署前需备份数据库并确认 HTTPS/传输策略。回退必须保留版本撤销检查，不能降低 `auth_version`、删除凭据或直接回到忽略撤销的旧程序。

本轮不是线上发布验收，也不是新一次 QQ 实际送达、真实模型生成或下载应用独立重建验收。旧人工评审 C-EB11、OAuth 草稿及其他历史未完成项不自动勾选。测试覆盖不意味着任意网络竞态、规模化爆破防护或生产性能已验证。
