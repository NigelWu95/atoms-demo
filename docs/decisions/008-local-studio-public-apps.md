# ADR-008 · 本地创作平台，仅公开已发布应用

## 状态

已被 [ADR-011](011-single-server-release.md) 的单服务器部署方向取代（2026-10-08 用户确认）。以下保留 2026-10-07 的历史决定，不再作为当前部署要求；网关/隧道没有上线。

## 决定

创作工作台继续运行于本机 5173，后端 8080、数据库 5432 和测试入口均不直接暴露。计划增加独立回环公开网关端口（暂定 8090），ngrok 仅将该端口映射为公网 HTTPS。该入口只允许 `/a/:slug`、公开外壳静态资源、`/api/public/apps/...` 及公开访客所必需的会话/CSRF 接口；默认拒绝其他路由，不提供创作 SPA fallback，不代理 `/api/projects`、生成、私有预览、测试页或诊断入口。

公网域名共享，应用用不同 slug 区分；不为每次发布启动进程或独立隧道。点击发布固定一个已检查的不可变版本，编辑不会自动更新公网版本；更新需要再次发布，下线只关闭发布指针，不删除源码和数据。LIVE 与 PREVIEW 状态隔离，公开访客之间隔离。

访问边界是网关路径/方法白名单加服务端授权，不是端口号本身。不信任访客提供的转发头；HTTPS Cookie、公开会话隔离、请求体上限和禁用流量检查/日志中的凭据需在 T29 验证。模型密钥和调用接口不进入公开入口。

## 依赖与验证

先完成 T25 的脚本语法/启动检查和持久报告，再实现 T26–T28 发布全链路，最后接入本地网关和隧道。应验证：未发布/下线 404、旧公网版本拒绝写、私有路径及编码绕过均被拒绝、不同访客独立保存、电脑/服务重启保留状态。

ngrok 命令当前未安装；不开启隧道、不变更账号或读取 authtoken。实际接入时需要用户在本地配置凭据和可用域名，再做外网验收。免费方案存在配额及浏览器提示页，额度和可用性以账号为准；本机休眠、关机、断网会使链接不可用，不承诺持续托管 SLA。

挑战原文要求可测试在线访问链接；当前选择可提供“生成应用”的公网链接，但不提供在线创作工作台。如果评审要求在线体验生成过程，需要提前说明，并以本地演示/录屏补充，或另行获批开放受保护工作台。
