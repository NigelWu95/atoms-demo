# 本地独立端口发布

2026-10-29 已在本地实现和验收。平台管理每个项目的独立应用进程；浏览器通过该项目的端口直接访问，不增加内部路径转发、隧道或远程服务器。

## 使用

1. 在完整工程工作台点击右上角“本地发布”。未构建时先选择源码并“构建选中源码”；已有成功构建时会核对数据库迁移。
2. 如存在新增迁移，查看 SQL 并批准，然后点击“启动并本地发布”。等待进程就绪，页面显示“打开本地应用”和可复制地址。
3. 点击链接在新窗口访问真实 Vue + Spring Boot 应用。应用自己的账号和业务数据由该项目的 PostgreSQL 保存；不要求访问者登录平台。
4. 下线时打开“本地发布”或“构建与运行”，点击运行记录中的“停止 / 下线”。平台正常停止原进程，数据库与源码保留。

每个项目复用自己已分配的端口和数据库，一次只保留一个运行。更新已构建的新版本时使用“更新本地应用”，等待原运行停止，再按页面提示重试原替换请求；切换有短暂中断，不会自动回滚业务数据库。仅提交需求、保存源码或构建不会自动替换当前运行版本。

关闭网页或退出平台账号不会停止应用。停止平台服务会结束其管理的应用，本轮没有增加平台重启后的应用自动启动；重新进入工作台即可启动保留的成功构建。

## 地址与访问边界

当前 2048 示例为 `http://localhost:18203/`，**仅在运行平台的本机可访问**。应用仍只监听 `127.0.0.1`。不同端口区分不同进程；没有增加新发布状态表，“已就绪运行”就是可直接访问的本地应用。

平台在 `127.0.0.1` 上打开时，应用链接使用 `localhost`；平台 origin 为 `localhost` 时则反过来。Cookie 按主机而非端口区分，这样不会主动把当前平台主机的 Cookie 带到应用的新窗口。链接带 `noopener noreferrer`。业务页面直接运行，不经过平台预览代理；独立进程并不是操作系统沙箱。

查询链接的 API 为 `GET /api/projects/{projectId}/delivery/runs/{runId}/address`。它核对当前所有者会话、源码 / 构建身份、协调器实际持有的进程和绑定端口，响应不缓存；不接受客户端指定端口或主机。未就绪、停止中、已停止、原进程丢失或跨用户查询均拒绝。平台 origin 不是本机地址时不生成这种本地链接，避免把服务器地址误解释成访问者自己的电脑。

工作台内的受控预览和下载继续保留。直接访问、预览和“下载当前预览源码”对应同一个运行构建；下载仍不包含数据库现有数据和私有配置。旧版 `/a/:slug` 发布不承担新工程的直接端口访问。
