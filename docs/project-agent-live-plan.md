## 次数与限制

- 建议本轮最多 **2 次 Claude Code 会话启动**，失败、取消或结果未知均占用次数，不自动补发或退回。
- 保持现有每任务上限：128000 输出 tokens、24 轮、1800 秒。并发配置仍为 4，本次同一个项目顺序执行两轮。
- 一次会话可包含多次模型 API 请求，因此“两次启动”不是“两次 API 调用”，也不是人民币金额硬上限。若需要金额硬上限，必须先确定由提供方或额外计费控制如何落实，不能用 token/启动次数冒充。
- 预检 `agent_live_budget.used=5`，其中可能包含既有受控测试预留，不能解读成真实请求或费用。授权两次后，临时累计上限应为开始前真实计数 **+2**；当前快照对应 7。不得清零或覆盖原记账。
- 默认 live 开关仍关闭、上限仍为 0。执行配置使用临时私有配置，结束后停止自有协调器与应用，保留源码/任务/停止证据；不推送或部署。
