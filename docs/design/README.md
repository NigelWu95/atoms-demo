# Atoms Demo：挑战分析与设计文档

研究日期：2026-10-07。状态：实施中。代码位于本仓库 backend/frontend；T01–T03 已通过本地验收，当前未实现真实生成或公网部署。任务进度以 tasks/todo.md 为唯一清单。

## 建议决策

采用 **Spring Boot + Vue 3 + PostgreSQL**，实现一个通过自然语言生成、运行、修改和发布小型交互应用的平台。优先完成“创建项目 → 真实模型生成代码 → 浏览器预览 → 继续修改 → 数据持久化 → 在线访问”的完整流程。

平台自身使用前后端分离架构；首版生成的应用使用 HTML/CSS/JavaScript，通过平台提供的受限数据接口保存业务状态。生成应用的技术栈与平台技术栈可以不同。后续再增加 Vue SFC 编译、独立后端生成和容器运行环境。

这是一项 6–8 小时原型交付建议，不是对完整商业平台工作量的估计。时间预算以开发者熟悉 Java/Vue、模型接口可用、部署环境可访问为前提。

## 三个关键区别

1. **平台持久化与应用数据持久化**：项目、聊天、代码版本需要保存；生成的待办事项等业务数据也要能保存。首版同时覆盖，后者采用按访问者隔离的 JSON 状态。
2. **生成完成与验证通过**：模型返回代码不代表页面正确；页面成功加载也不代表业务流程正确。界面分别展示生成状态、预览检查和人工体验结果。
3. **编辑版本与公开版本**：新生成的代码不会自动替换公开应用；用户发布后才更新公开版本指针。

## 推荐范围

- P0：访客会话、项目列表、自然语言生成与修改、真实进度事件、源码查看、版本保存、交互预览、应用状态保存、固定版本发布、在线部署和最终验收。
- P1 优先：历史版本恢复；错误辅助修复、注册登录和源码导出不计入基础冲刺承诺。
- P2 / 后续：可视化点选修改、完整代码编辑器、截图输入、模板 Remix、多人协作、Race Mode、外部集成、任意依赖构建、独立应用后端。

## 当前假设与尚待落实的条件

- 默认以桌面编辑体验为主，生成应用需适配移动端。
- 尚未确认模型 API、服务器、域名、Java/Go 熟练度，选型依用户优先级使用 Java/Vue。
- 模型服务通过服务端适配层接入；具体协议和模型必须在开工前做小请求验证。
- Atoms 提供的 70 美元额度是参考平台的使用资源，不应视为自建 Demo 的模型 API 或服务器额度。
- 默认公开应用的数据按访问者隔离，不承诺多用户共享看板、跨设备同步或生成应用自己的账号系统。
- 所有时延、容量和工时都是设计目标，未经过本项目实测。

详细开发计划以 8 小时为冲刺时间盒，目标第六小时得到完整候选版本，之后优先回归、修复与提交；只有 P0 稳定才做历史恢复。这不是保证全部机制能从零在 8 小时实现的工期承诺。

开工入口为 [T00：冻结实施基线](tasks/todo.md#t00--冻结实施基线)。数据库暂沿用 PostgreSQL；若已有更熟悉的 MySQL 环境，可在开工时一次性替换，不同时维护两套实现。本地基础网站已实现，继续按任务清单推进。
