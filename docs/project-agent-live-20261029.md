适配器现在仅在初始化成功后接收形状有效、计数非负的 thinking 进度通知。这些估算不作为最终用量或生成成功依据。高频进度另设 262144 项上限，工具协议仍为 4096 项，两者共用原有单行 4 MiB、总流 64 MiB 和任务期限限制。非法工具、路径、权限、缺失最终结果仍拒绝。

诊断新增固定原因分类：协议拒绝、流量限制以及 CLI 最终失败原因。明确的最大轮数失败显示为 `AGENT_TURN_LIMIT`；其他未完成结果保持 `AGENT_MODEL_INCOMPLETE`。日志只保存固定分类、事件序号、类型指纹及任务标识，不保存原始模型内容或密钥。

修复后定向回归：**57 项单元测试、14 项集成测试通过，0 失败/错误/跳过**。包含真实 CLI thinking、提供方错误、工具边界、连续编辑和协调器租约检查；这些回归使用假模型服务，不计为真实 DeepSeek 功能验收。日志：`.local/ex22-agent-live-final-20261029.log`。
