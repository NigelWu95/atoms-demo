## 可复现命令

要求 Node 24.20.0、Java 17.0.5-oracle、现有专用 `atoms_demo_test` / `atoms_test` 和私有测试数据库配置，8081/5174 空闲。不要把测试指向平台运行库。

在 `frontend/` 执行（先在当前终端配置 Node PATH 与 JAVA_HOME，不改系统配置）：

```sh
npm run test:unit
npm run typecheck
npm run lint
npm run format:check
npm run build
CI=1 npx playwright test --config playwright.entry.config.ts
CI=1 npx playwright test --config playwright.runtime.config.ts
```

新增 `playwright.entry.config.ts` 复用运行时夹具的测试后端和 5174 前端：禁止真实模型执行，邮件由测试适配器捕获，不使用 QQ SMTP。17 项完整验收使用既有私有等价配置 `.local/iteration-browser.config.ts`；新增仓库配置随后实际启动并通过 `foundation.spec.ts` 全部 8 项（重复验证，不额外计入独立用例总数），截图在 `frontend/test-results/entry/`。不要为了查看 Playwright 启动日志把通用 `DEBUG` 环境变量传给 Spring，避免意外开启含响应细节的后端调试日志。

## 登录返回补充（2026-10-17）

用户确认按「首页保留 idea、项目重新鉴权、直达默认列表」实施；不改变后端账号归属、验证码或会话机制。来源链接携带白名单内的 `returnTo`，成功登录后 `router.replace`；账号管理页与跨标签更新不会触发自动跳转。详情见[账号说明](https://github.com/NigelWu95/atoms-demo/blob/main/docs/email-accounts.md#登录后的返回与内容保留)。

实现与安全边界：

- 仅首页来源的当前标签页在显式验证成功后带回内存 idea；私有项目草稿、生成恢复记录仍由会话切换清空，其他标签页不继承输入。已保存项目内容从服务端重读，不承诺还原未保存的编辑或首页刷新后的输入。
- 项目及私有预览先调用现有项目读取 API；404 时返回列表并提示，暂时失败时留在已登录页允许重试。检查中离页、修改返回目标、切换账号的迟到结果被忽略。
- 返回地址只接受 `/`、`/projects`、`/workbench`、UUID 项目/私有预览路径；拒绝外部 URL、数组、账号循环、API、query/hash 与路径穿越。URL 和新增代码不保存邮件验证码、邮箱、密钥或 idea。
- session transition 仅增加明确的成功/未完成返回值，便于页面区分自己的登录成功与被中断操作；保留原有 Cookie/CSRF、私有缓存清理、SSE 停止及跨标签机制。未增加后端 API、数据库迁移或依赖。

## 验证码表单重校验修复（2026-10-17）

用户报告发送验证码后表单退回空邮箱输入，只剩冷却倒计时。根因是 `AccountPage` 监听了一个返回新数组的 getter；标签页恢复可见时，真实 `reconcile()` 用新对象更新同一身份，数组引用变化便误触发表单清理。发送冷却是单独状态，因此仍显示剩余秒数。

修复仅调整前端监听源：逐项比较会话 revision、用户 ID 与访客/账号类型。相同身份重新校验不清空表单；身份切换或会话失效仍清理。未持久化邮箱挑战或验证码，不更改后端认证、有效期、限流、Cookie、邮箱配置或模型额度。

回归证据：新增组件用例在修复前确实复现空邮箱，另一个用例复现仅 revision 改变时未清理；修复后账号组件 24 项通过，全前端 49 文件 / 329 项通过，typecheck、lint、format:check 和生产构建通过。浏览器新增用例通过测试发件器发送一次，重放两次 `visibilitychange`，每次使用真实 `/api/me` 与 CSRF 刷新，保留部分验证码和冷却，最后用原验证码登录并返回首页；修复前失败、修复后通过。

完整入口/邮箱/项目 Chrome 套件 **18 项通过（2.4 分钟，零重试）**，包含跨标签账号变更、退出后再登录、无效验证码、登录返回和 320/390/768/1024/1440px 的布局/axe 检查。已对比修复前后截图：前者只剩空邮箱与冷却，后者保留验证码输入和验证按钮。此次没有重跑全量后端、工作台 runtime 或公网验收；这些历史通过数不计入本轮。
